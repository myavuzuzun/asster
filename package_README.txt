OVERVIEW:
  Asster is a precision mastering processor designed specifically for high-density,
  high-energy mixes (Metal, Rock, Electronic, Modern Commercial Audio).

  Featuring:
  - 100% Zero-Clipping Guarantee via True Peak Lookahead Brickwall Limiter
  - AutoTrim Input Normalization (-18 LUFS nominal sweet spot)
  - 4-Band Sculpting Mastering EQ (Sub Cut, Bass Punch, Mud Scoop, Bite, Air Sheen)
  - Analog Tape / Tube / Solid-State Harmonic Saturation
  - Stereo M/S Processor with Mono-Bass Crossover
  - Bus Glue Compressor & Pro Soft Clipper
  - Hardware-Accelerated Direct2D / DirectWrite UI with EBU R128 Precision Metering Deck
  - 7 Engineered Genre Presets:
      0. EXTREME     (-8.0 LUFS, -0.8 dBTP)
      1. DOOM        (-10.5 LUFS, -0.5 dBTP)
      2. SLUDGE      (-9.0 LUFS, -0.6 dBTP)
      3. GROOVE      (-8.5 LUFS, -0.5 dBTP)
      4. DJENT       (-7.5 LUFS, -0.5 dBTP)
      5. CLASSIC     (-11.0 LUFS, -0.5 dBTP)
      6. TRANSPARENT (-14.0 LUFS, -1.0 dBTP - Streaming compliant)

INSTALLATION:
--------------------------------------------------------------------------------
1. VST3 Plugin (Recommended for Modern DAWs):
   Copy 'Asster.vst3' to your system VST3 directory:
     C:\Program Files\Common Files\VST3\
   or user VST3 directory:
     %LOCALAPPDATA%\Programs\Common\VST3\

2. VeSTige Plugin DLL (Legacy DAWs / LMMS / Older Hosts):
   Copy 'Asster.dll' to your DAW's 64-bit plugin directory, such as:
     - LMMS: Documents\lmms\plugins\vst\
     - REAPER: AppData\Roaming\REAPER\UserPlugins\
     - Standard: C:\Program Files\VstPlugins\ or Documents\VstPlugins\

3. Standalone Host:
   Run 'asster_standalone.exe' directly to audition and test the native UI in real time!
